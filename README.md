## 🚀 Live Preview & Deployment

### Run Locally
Simply open `index.html` in any modern web browser or serve via a lightweight HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js / npx
npx serve .
```

Navigate to `http://localhost:8080` to experience the portfolio live.

### Deploy in One Click

| Platform | Deployment Instructions |
|---|---|
| **GitHub Pages** | Go to **Settings** → **Pages** → Source: **Deploy from a branch** (`main` / root) → Save. |
| **Vercel** | Import the repo into Vercel Dashboard → Output Directory: `.` → Deploy. |
| **Netlify** | Drag and drop this folder directly into the Netlify Drop app for instant hosting. |
